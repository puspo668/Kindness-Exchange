# Kindness Exchange

Kindness Exchange is a web-based donation management system developed using HTML, CSS, PHP, and MySQL.
The platform connects donors and receivers for blood, books, and clothes donation.



## Features

* Blood Donation Module
* Book Donation Module
* Cloth Donation Module
* Donor Search System
* District-Based Filtering
* Receiver Request Forms
* Dynamic Homepage
* Donation Statistics


## Technologies Used

* HTML5
* CSS3
* JavaScript
* PHP
* MySQL
* XAMPP


## Modules

### Blood Donation

Users can register as blood donors and receivers can search donors by district.

### Book Donation

Users can donate books and receivers can request books from donors.

### Cloth Donation

Users can donate clothes and receivers can request clothes.



## Database

Database Name:

registration_db



## How to Run the Project

1. Install XAMPP
2. Start Apache and MySQL
3. Copy the project folder into:

C:\xampp\htdocs\kindness_exchange\bookdon

4. Create a database named:

registration_db

5. Import or create required tables from:

database.sql

6. Open browser and run:

http://localhost/kindness_exchange/bookdon/homepage.php
